\section*{Data and code availability}
All code, stored results, trained network weights and verification scripts are available at \url{https://github.com/neginyan/cld-corrected-sampler} and archived at Zenodo, \href{https://doi.org/10.5281/zenodo.23689208}{doi:10.5281/zenodo.23689208}.
Every number in this paper is recomputed from the stored results by a verification script.
No GPU was used.
