## 記号と単位
- 山の位置の標準偏差 s を長さの単位にとる(s = 1)。線形の問題なので、結果は比 σ_min/s、σ_max/s、v_std/s だけで決まる(検査で確かめる)。
- 時間は β で決まる。r/κ を固定すれば β は結果に効かない(検査で確かめる)。
- CLD の流れの族:B = β[[0, M⁻¹], [−1, −ΓM⁻¹]]、Γ = 2√M(CLD-SGM のコードと同じ臨界減衰。M を変えても臨界のまま)。
- 「縮み」:L = log[(i) の山の中の位置の分散 / 正しい値]。**「10% 以上の縮み」は L ≤ log 0.9 = −0.1054** とする。
- B1 の既定値:σ_min/s = 0.0625、σ_max/s = 500、v_std/s = 1.25、M = 1/4。

## §2-1 式(導出)
- 主張する式は、正確な ODE(山 1 個のガウス理論)と、5 点以上のパラメータで比べる。
  - 恒等式・厳密な関係:相対誤差 ≤ 1e-6。
  - 主要な次数(漸近形):報告の中でその式ごとに許容誤差を書き、その誤差は 5% 以下とする。
- 線形応答(r → κ での傾き)は、r/κ = 0.99 で全体の ODE と 2% 以内で合うこと。

## §2-2 地図
- ODE の精度:許容誤差 rtol を 1e-10 から 1e-12 にしても、L の変化が相対 1e-6 以下。
- 「10% を超える領域があるか」は、あってもなくても結果として報告する(合否ではない)。

## §2-3 混合での確認(2〜3 設定)
B1 と同じ方法(正確なスコア、(i)(ii)(iii)、対にした比較、刻み 2 段と外挿、N = 40000、種 5 つ)。
- 刻みの収束:対にした L について |fine − coarse| ≤ 15% × |外挿値|。
- (i) の縮みが有意:平均 + 2 標準誤差 < 0。
- **成功**:選んだ設定のうち少なくとも 1 つで、混合の対にした L の平均 ≤ −0.1054(10% 以上の縮み)。
- (ii)、(iii):真値に対する |L| ≤ 3 標準誤差 + 0.01。B1 の 0.003 より緩めるのは、σ_min/s や r/κ を大きく動かすと刻みの誤差が変わりうるため。外挿後にこれを超えたら FAIL として報告する。
- 山ごとの重み:|w_k − 1/8| の最大 ≤ 0.01(ただし、σ_min を山の間隔に近づけた設定で山どうしが重なる場合は、重みを測る割り当ての規則自体が曖昧になるので、その設定では参考値とする)。
- 測定/理論の比は報告する(合否ではない)。
