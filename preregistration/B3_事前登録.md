## スコアの誤差の測り方
- 各 σ(log 一様に 40 点)で、その σ の前向きの周辺分布から新しく 20 000 点引き、相対誤差 e(σ) = E|s_θ − s|² / E|s|² を、位置成分と速度成分に分けて測る(s は正確な混合のスコア)。
- 「σ_min の近くの誤差」の代表値:e を σ ∈ [σ_min, 2σ_min] で平均したもの(B2 の §3.2 による)。

## サンプリング
- 3 つのサンプラー(B1 と同じ式)を、最後の EMA の重みで走らせる。N = 20 000、刻み h = T/⌈T/0.002⌉、サンプリングの種 0、1、2(事前分布は rng(100 + 種)、ブラウン増分は rng(200 + 種))。
- **同じ事前サンプル・同じブラウン増分で、正確なスコアでも走らせる。** 離散化の誤差は両方に共通に入るので、「学習 − 正確」の差 Δ はスコアの誤差だけによる。
- 比べる相手は σ_min でぼかしたデータ(B2 と同じ)。山の中の位置の分散で L = log(分散 / 正しい値) を測る。

## 成功の基準(B と C で判定。D は報告のみ)
- **S1((i) は学習したスコアでも壊れる)**:学習したスコアの対にした L((i)/(ii))について、平均 + 2 標準誤差 < 0、かつ正確なスコアの対にした L との比が 0.75〜1.25。標準誤差は、ネットワーク 2 本 × サンプリングの種 3 つ = 6 本の値から計算する。
- **S2((ii) は学習したスコアでも直る)**:学習したスコアの (ii) について、|Δ_ii| = |L_ii(学習) − L_ii(正確)| ≤ 0.03(3%)、かつ |Δ_ii| < |学習したスコアの対にした L| / 3(残りが、直したい縮みの 1/3 未満)。
- (iii) も同じ量を報告する(合否ではない)。
- **S3(スコアの誤差とずれの関係)**:B と C で、ネットワークの種 1 のチェックポイント 10k、40k、100k、300k を、サンプリングの種 0、N = 10 000 で走らせ(学習と正確の対)、Δ_i、Δ_ii、Δ_iii と、σ_min の近くの誤差の関係を示す。合否ではなく、関係(単調か、比例か)を報告する。
- 予言(確かめる前の見込み):学習したスコアでは、(i) と (ii) に同じ向きのスコア誤差が入るので、対にした L は正確なスコアのときと近い値になるはず。(ii) の残りは、スコアの誤差が小さいほど小さくなるはず。
